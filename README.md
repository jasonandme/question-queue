# 追问清单 · Question Queue

一个本地优先的浏览器扩展：在阅读大模型回答时随手记录新疑问，并在下一轮对话中一键填入，无需来回复制粘贴。

## 当前功能

- 支持 ChatGPT、Claude、Gemini、DeepSeek、Grok、Poe、Copilot、豆包和腾讯元宝。
- 点击网页右下角 `?`、浏览器工具栏图标或按 `Alt+Shift+Q` 打开侧边栏。
- 选中回答中的文字，右键选择“记录为追问”，自动保留上下文和来源链接。
- 用“待输入 / 已输入 / 已回答 / 已掌握”四种状态管理学习进度。
- 单条或批量一键填入当前模型的输入框；填入后由用户确认发送。
- 在可识别的网站上，新回答生成后会尝试自动切换为“已回答”；也可手动切换。
- 支持搜索、编辑、学习笔记、重新追问、JSON 导入与导出。
- 数据只保存在浏览器本机，不上传服务器。

## 安装测试

1. 打开 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录 `question-queue-extension`。
5. 打开受支持的大模型网页并刷新一次。

## 典型使用流程

1. 阅读回答时选中关键文字，右键记录为追问。
2. 在侧边栏补充疑问，保存后进入“待输入”。
3. 点击“一键填入待输入”，插件将多个问题编号后填入当前输入框。
4. 确认并发送，状态显示为“已输入”。
5. 回答生成后标为“已回答”，学习完成后标为“已掌握”。

## 隐私与权限

扩展只申请本地存储、右键菜单、当前标签页及受支持模型站点的访问权限。它不会自动发送消息，不读取账号密码，也不把问题同步到远程服务器。

## MVP 的已知限制

- 各模型网站会不定期改版，“一键填入”和自动识别回答可能需要更新选择器。
- 当前数据只在单台浏览器本地保存。云同步、账号系统和团队空间留到商业版。
- 当前没有自动发送，以避免误发隐私内容或产生不可逆的外部操作。
