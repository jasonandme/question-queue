# 追问清单 · Question Queue

一个本地优先的浏览器扩展：在阅读大模型回答时随手记录新疑问，并在后续对话中一键追加，无需来回复制粘贴。

## 当前功能

- 支持 ChatGPT、Claude、Gemini、DeepSeek、Grok、Poe、Copilot、豆包和腾讯元宝。
- 默认打开 Edge/Chrome 原生侧边栏：它与模型网页并排显示，网页会自动缩窄，不再遮挡回答；旧浏览器才回退到网页抽屉。
- 点击网页右下角问号、浏览器工具栏图标或按 Alt+Shift+Q 均可打开。
- 选中回答中的文字，右键选择“记录为追问”，自动把选中文字放入“相关上下文”，同时保留来源链接。
- 用“待输入 / 已输入 / 已回答 / 已掌握”四种状态管理学习进度。
- 填入操作只会追加到输入框末尾，不会覆盖已经输入但尚未发送的内容。
- “待输入”和“已输入”都支持多选批量填入；浏览器重启后可从“已输入”中重新选择并恢复。
- 支持搜索、编辑、学习笔记、重新追问、JSON 导入与导出。
- 可按需调用千问 `qwen3.8-max`，把问题按主题整理为可回顾的层级思维导图。
- 可离线导出 `.docx` Word 文档，内容包含思维导图、问题状态、上下文与学习笔记。

## 安装与更新

1. 打开 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`。
2. 开启“开发者模式”。
3. 首次安装时点击“加载已解压的扩展程序”，选择本目录 `question-queue-extension`。
4. 更新代码后，在扩展卡片上点击“重新加载”。
5. 打开受支持的大模型网页并刷新一次。

更新到 0.3.0 后必须先在 edge://extensions 的扩展卡片上点击一次“重新加载”，再刷新已经打开的大模型网页。工具栏图标现在直接打开浏览器原生侧边栏，不再显示旧弹窗。若点击没有反应，依次检查：扩展是否启用、是否已重新加载、模型网页是否已刷新；也可以按 Alt+Shift+Q 测试。

## 填入与多选

- 单条“填入”和批量填入都会保留输入框现有文字，并在末尾空两行后追加问题。
- “一键填入待输入”会追加全部待输入问题。
- 在“待输入”或“已输入”标签中勾选多条问题，再点击“填入所选”。
- “已输入”中的问题提供“再次填入”，适合浏览器重启、网页刷新或输入框内容丢失后的恢复。
- 插件不会自动点击发送，用户可以在发送前继续修改。

## 相关上下文

“选中文字并右键记录”是指：在模型回答中用鼠标选中一段原文，右键点击“记录为追问”。插件会打开编辑器，并把选中的原文自动放入“相关上下文”。普通点击悬浮按钮新建问题时不会自动带入内容。

## 千问思维导图设置

1. 立即吊销任何已经公开或粘贴到聊天中的旧 API Key，并重新生成。
2. 点击浏览器工具栏中的“追问清单”图标，打开原生侧边栏。
3. 在侧边栏顶部进入“设置”。
4. 从阿里云百炼控制台复制当前工作空间的 OpenAI 兼容 Base URL，例如：
   `https://你的WorkspaceId.cn-beijing.maas.aliyuncs.com/compatible-mode/v1`
5. 填入新 API Key 并保存。
6. 在侧边栏顶部进入“思维导图”，再点击“生成思维导图”。

智能分析只在用户主动点击生成时执行，只发送问题文本、状态和匿名问题 ID；不发送相关上下文、学习笔记、来源网址或回答原文。API Key 保存在浏览器扩展的本地存储中，不会包含在 JSON 或 Word 导出文件里。生产版建议改用服务端令牌代理，避免长期在客户端保存密钥。

## 数据备份与 Word 导出

- “导出”生成 JSON 完整备份，包含问题和最近一次思维导图。
- “导入”会按问题 ID 合并数据。
- “Word”在本机离线生成 `.docx`，不会为导出文档调用外部服务。

## 隐私与权限

扩展申请本地存储、右键菜单、当前标签页、浏览器原生侧边栏、受支持模型站点及阿里云百炼官方 API 域名的访问权限。阿里云域名权限仅用于用户主动发起的思维导图分析。扩展不会自动发送模型对话，不读取账号密码，也不会出售用户数据。

## 已知限制

- 各模型网站会不定期改版，“追加填入”和自动识别回答可能需要更新选择器。
- 当前问题数据只在单台浏览器本地保存；JSON 可以用于手动迁移。
- API Key 的客户端本地保存适合个人原型，不适合直接作为面向公众的商业版密钥架构。
