# 追问簿 · Question Queue

一个面向大模型网页的本地优先浏览器扩展。阅读回答时随手记录疑问，在下一轮对话中批量追加，不用反复复制粘贴，也不会覆盖输入框里已有的草稿。

Question Queue is a local-first browser extension for collecting follow-up questions while reading LLM responses and appending them to a later prompt.

## 为什么做这个扩展

长回答往往会连续引出多个问题。立即追问会打断阅读，先记在别处又会产生复制、整理和回填成本。追问簿把这段流程收进浏览器侧边栏：

1. 阅读回答，不中断当前思路。
2. 随手记录问题，必要时保留引发问题的原文。
3. 按对话、标签和学习状态整理。
4. 选择一条或多条问题，追加到当前输入框。
5. 回答后标记为“已回答”或“已掌握”，形成可回顾的问题档案。

## 功能

- Edge / Chrome 原生侧边栏，与模型网页并排显示。
- 网页右下角快捷按钮和 Alt+Shift+Q 快捷键。
- 选中回答文字后，通过右键菜单记录为追问。
- 填入时只追加，不覆盖输入框里的已有文字，也不会自动发送。
- 待输入、已输入、已回答、已掌握四种状态。
- 待输入和已输入记录均支持多选、批量填入与再次填入。
- 自动识别当前对话标题和稳定链接，默认按对话分组。
- 支持手动标签、对话筛选、标签筛选和全文搜索。
- JSON 备份与合并导入。
- 本地生成 Word 文档，包含状态、对话、标签、上下文和笔记。
- 可选接入阿里云百炼 qwen3.8-max，按需生成问题思维导图。
- 不支持原生侧边栏的旧浏览器会回退到网页内抽屉。

## 安装

### Edge

1. 下载源码，或下载 Release 中的压缩包并解压。
2. 打开 edge://extensions。
3. 开启“开发人员模式”。
4. 点击“加载解压缩的扩展”，选择包含 manifest.json 的目录。
5. 打开受支持的模型网站并刷新一次。

### Chrome

1. 下载并解压项目。
2. 打开 chrome://extensions。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择项目目录。
5. 刷新已经打开的模型页面。

更新源码后，需要在扩展管理页面点击“重新加载”，再刷新模型网页。直接覆盖旧目录并重新加载，可以保留浏览器本地数据；删除扩展通常会同时删除本地记录，操作前请先导出 JSON 备份。

## 使用

### 记录问题

- 点击工具栏图标、网页右下角问号，或按 Alt+Shift+Q。
- 在侧边栏顶部写下问题。
- 标签支持中文逗号、英文逗号、分号或换行分隔。
- 点击“保存疑问”，记录进入“待输入”。

### 带入回答上下文

在模型回答中选中一段文字，右键选择“记录为追问”。选中的内容会追加到编辑器的“相关上下文”，用于说明这个疑问由哪段回答引发。连续划词不会覆盖之前的上下文。

### 批量填入

- “一键填入待输入”会按记录时间追加全部待输入问题。
- 也可以勾选若干条记录，点击“填入所选”。
- 已输入的问题可再次填入，适合网页刷新或浏览器重启后恢复草稿。
- 扩展只修改输入框，不会代替用户发送消息。

### 对话和标签

新记录会保存平台、对话标题、来源链接和对话标识。对话标识优先采用去掉查询参数的对话 URL，页面标题只用于显示。这样可以尽量避免同名对话被混在一起。

旧记录没有对话字段时，会根据原有来源链接和标题即时归组，不需要迁移脚本。

## 可选的千问思维导图

思维导图功能默认不联网，只有用户主动点击“生成思维导图”时才会调用接口。

1. 在阿里云百炼创建独立、可撤销且设置了额度的 API Key。
2. 打开侧边栏的“设置”。
3. 填写工作空间的 OpenAI 兼容 Base URL 和 API Key。
4. 进入“思维导图”，点击生成。

请求只包含问题文本、状态和匿名问题 ID，不包含相关上下文、学习笔记、来源网址或完整模型回答。API Key 保存在浏览器扩展本地存储中，因此公开部署或商业化版本应使用服务端令牌代理，不应把共享密钥放进扩展。

## 数据与隐私

- 问题、上下文、标签、笔记、状态和设置保存在 chrome.storage.local。
- 项目没有同步服务器、统计脚本、广告 SDK 或错误追踪服务。
- Word 文档在本机生成。
- JSON 和 Word 导出不包含千问 API Key。
- 卸载扩展前应先导出 JSON 备份。

完整说明见 [PRIVACY.md](PRIVACY.md) 和 [SECURITY.md](SECURITY.md)。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| storage | 保存问题、状态、标签、思维导图和用户设置 |
| contextMenus | 提供“记录为追问”右键菜单 |
| activeTab | 向当前模型页面追加选中的问题 |
| sidePanel | 在浏览器原生侧边栏中显示清单 |
| 模型站点访问权限 | 注入快捷按钮并识别当前输入框 |
| 阿里云百炼域名权限 | 仅在用户主动生成思维导图时请求接口 |

## 项目结构

~~~text
background.js       后台事件、右键菜单、侧边栏与千问请求
content.js          模型网页适配、输入框追加与兼容抽屉
sidepanel.*         原生侧边栏界面和本地数据管理
docx-export.js      本地 Word 文档生成
vendor/             JSZip 及其许可证
scripts/            无依赖的发布前检查
docs/               架构和迭代决策记录
~~~

## 设计与演进

这个项目从单条追问记录开始，逐步加入可靠填入、批量恢复、学习状态、思维导图、Word 导出、原生侧边栏、对话分组和标签。每次变化解决的具体问题、被放弃的方案和取舍记录在 [开发决策](docs/DEVELOPMENT_NOTES.md) 中；版本变化见 [CHANGELOG.md](CHANGELOG.md)。

## 开发

项目是原生 Manifest V3 扩展，没有构建步骤，也不需要安装依赖。

~~~bash
node --check background.js
node --check content.js
node --check sidepanel.js
node --check docx-export.js
node scripts/validate.mjs
~~~

提交修改前请阅读 [CONTRIBUTING.md](CONTRIBUTING.md)。
